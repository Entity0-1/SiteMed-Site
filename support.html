SiteMed support

Start with the simple checks.

Most scan problems can be resolved by reopening the page, checking Chrome’s access prompt, or running the scan again after the website finishes loading.

SiteMed cannot check this page

  1. 1

    Reload the webpage and wait for it to finish opening.

  2. 2

    Select the SiteMed toolbar icon and choose Check again.

  3. 3

    Confirm that the tab is a normal HTTP or HTTPS webpage.

Chrome prevents extensions from inspecting browser settings, the Chrome Web Store, new-tab pages, and some built-in or protected pages.

An audit or monitor did not start

Whole-site audits and availability monitoring need optional access to the specific website. Start the action again and accept Chrome’s site-access prompt. SiteMed stops if that permission is declined.

A result looks incorrect

Select Check again after the page settles. Dynamic pages can change after opening, and loading results can vary with the connection, cache, device, and browser-window size.

Use the finding’s Advanced explanation when reporting the issue. Do not include passwords, payment details, private form entries, or other sensitive information in a support request.

Remove saved information

Open the SiteMed dashboard and remove an individual saved website. To remove everything, clear SiteMed’s extension data in Chrome or uninstall the extension.

Need more help?

Use the official support channel.

After SiteMed is published, open its Chrome Web Store listing and select the Support section to send a question, bug report, or suggestion.

Helpful details to include

  • SiteMed version
  • Chrome version
  • What you expected
  • What happened instead
  • The affected website, only if you are comfortable sharing it

Common questions

Using SiteMed

Why did SiteMed find nothing?

It means the checks that completed did not find a listed problem. SiteMed cannot test every part of a website and may miss earlier errors, content inside another page, or content that appears later.

Why does SiteMed request access to a website?

The popup can inspect the active page without permanent site access. An audit or monitoring check must request pages from the saved website, so Chrome asks for that website’s permission when the feature is started.

Does SiteMed upload reports?

No. Reports remain in Chrome. Copying, exporting, printing, or saving a PDF happens only after the user chooses that action.
